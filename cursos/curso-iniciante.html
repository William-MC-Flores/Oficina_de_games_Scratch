Introdução ao Scratch

Scratch é uma plataforma visual de programação que permite criar histórias interativas, jogos e animações sem necessidade de conhecimento prévio em linguagens de programação tradicionais.

O que você vai aprender:

  • O que é Scratch? - Conheça a plataforma que revolucionou o ensino de programação para iniciantes em todo o mundo.
  • Criando sua conta - Aprenda como criar uma conta gratuita no Scratch e acessar todos os recursos disponíveis.
  • Navegando pela interface - Explore o ambiente principal onde você criará seus projetos.
  • Seu primeiro projeto - Crie um projeto simples para familiarizar-se com as ferramentas básicas.
  • Salvando e compartilhando - Entenda como salvar seus trabalhos e compartilhá-los com a comunidade Scratch.

Objetivos:

  • ✓ Compreender o conceito de programação visual
  • ✓ Navegar confortavelmente pela interface do Scratch
  • ✓ Criar e salvar seu primeiro projeto
  • ✓ Entender a filosofia de "aprender fazendo" do Scratch

Recursos inclusos:

  • 📹 5 vídeo-aulas explicativas
  • 📝 Guia passo-a-passo em PDF
  • 💻 Projeto inicial pronto para usar como referência
  • ❓ FAQ com dúvidas frequentes
2

Interface e Sprites

Sprites são os atores do seu mundo Scratch. Eles são imagens que podem se mover, mudar de aparência e interagir com outros sprites. A interface do Scratch foi projetada para tornar isso fácil e intuitivo.

O que você vai aprender:

  • O que são Sprites? - Entenda que sprites são os personagens e objetos que você usa para criar suas histórias e games.
  • Adicionando Sprites - Aprenda a adicionar novos personagens à sua cena, escolhendo da biblioteca do Scratch ou enviando seus próprios desenhos.
  • Editando Sprites - Modifique a aparência de seus sprites usando o editor integrado de desenho.
  • Organizando a cena - Coloque múltiplos sprites em camadas e organize seus projetos de forma profissional.
  • Entendendo os painéis - Explore os diferentes painéis: blocos, palco, lista de sprites e editor de código.

Objetivos:

  • ✓ Manipular sprites efetivamente
  • ✓ Trabalhar com múltiplos sprites em um projeto
  • ✓ Personalizar a aparência dos seus personagens
  • ✓ Compreender a estrutura de um projeto Scratch

Recursos inclusos:

  • 📹 6 vídeo-aulas práticas
  • 🎨 Sprites prontos para download
  • 📚 Documentação detalhada sobre a interface
  • 🎯 Exercícios práticos com solução
3

Movimentação de Personagens

Fazer seus personagens se moverem é o que traz vida aos seus projetos. No Scratch, você usará blocos de código visual para criar comportamentos e movimentos incríveis.

O que você vai aprender:

  • Blocos de movimento - Conheça os blocos básicos para mover seus sprites pelo palco (mover, girar, deslizar).
  • Controlando com o teclado - Aprenda a usar o teclado para controlar seus personagens interativamente.
  • Detectando bordas - Implemente código para que seus personagens não saiam da tela.
  • Criando sequências de movimento - Combine vários blocos para criar movimentos complexos e naturais.
  • Entendendo coordenadas - Trabalhe com coordenadas X e Y para posicionar precisamente seus sprites.

Objetivos:

  • ✓ Criar movimento fluido e responsivo
  • ✓ Implementar controle do jogador
  • ✓ Entender sistemas de coordenadas
  • ✓ Criar seu primeiro mini-game com movimento

Recursos inclusos:

  • 📹 7 vídeo-aulas interativas
  • 💻 Projetos de exemplo comentados
  • 📋 Cheat sheet de blocos de movimento
  • 🎮 Desafios práticos progressivos

Sons e Efeitos

Sons e efeitos visuais transformam seus projetos em experiências imersivas. Aprenda a adicionar áudio, criar efeitos de cor e transformação para deixar seus games ainda mais interessantes.

O que você vai aprender:

  • Adicionando sons - Explore a biblioteca de sons do Scratch e aprenda como adicionar áudio aos seus projetos.
  • Gravando sons personalizados - Use o gravador de áudio para criar efeitos sonoros únicos para seu projeto.
  • Controlando volume e velocidade - Manipule as propriedades dos sons para criar efeitos dinâmicos.
  • Efeitos visuais - Aprenda a usar blocos de efeitos de cor, fantasma e distorção para criar animações impressionantes.
  • Sincronizando som e imagem - Combine sons com movimentos e efeitos para criar uma experiência coerente.

Objetivos:

  • ✓ Trabalhar com sons e efeitos de áudio
  • ✓ Criar efeitos visuais atraentes
  • ✓ Sincronizar sons com ações do jogo
  • ✓ Personalizar a experiência do jogador com multimídia

Recursos inclusos:

  • 📹 6 vídeo-aulas com demos
  • 🎵 Biblioteca de sons royalty-free
  • 🎨 Guia de efeitos visuais
  • 🎬 Projeto final: Crie um game completo com sons e efeitos
