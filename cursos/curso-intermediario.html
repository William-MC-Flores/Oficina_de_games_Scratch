Variáveis e Listas

Variáveis são como caixas que armazenam informações. Listas são coleções de variáveis que permitem armazenar múltiplos valores. Esses conceitos são fundamentais para criar games interativos e dinâmicos.

O que você vai aprender:

  • Entendendo variáveis - Aprenda o conceito de variáveis como recipientes de dados que mudam durante a execução.
  • Criando variáveis - Crie variáveis personalizadas para armazenar informações importantes do seu game.
  • Modificando valores - Altere valores de variáveis durante a execução usando blocos "mudar".
  • Introdução a listas - Entenda como listas armazenam múltiplos valores em um único recipiente.
  • Operações com listas - Adicione, remova e acesse itens de listas para criar sistemas complexos.

Objetivos:

  • ✓ Compreender o conceito de variáveis
  • ✓ Criar e manipular variáveis em seus projetos
  • ✓ Trabalhar com listas e operações básicas
  • ✓ Implementar sistemas de pontuação e contadores

Recursos inclusos:

  • 📹 8 vídeo-aulas detalhadas
  • 📝 Guias práticos sobre variáveis
  • 💻 Exemplos de projetos com variáveis
  • 🎯 Exercícios progressivos com soluções

Loops e Condicionais

Loops permitem repetir código múltiplas vezes, enquanto condicionais permitem executar código apenas quando certas condições são atendidas. Esses são os blocos de construção da lógica de programação.

O que você vai aprender:

  • Condicionais IF/ELSE - Tome decisões no seu código baseado em condições verdadeiras ou falsas.
  • Operadores lógicos - Use AND, OR e NOT para criar condições mais complexas.
  • Loop REPITA - Execute um bloco de código um número específico de vezes.
  • Loop SEMPRE - Crie loops infinitos que continuam até serem interrompidos.
  • Loop REPITA ATÉ - Execute código até que uma condição seja atendida.

Objetivos:

  • ✓ Dominar estruturas de decisão (IF/ELSE)
  • ✓ Implementar loops corretamente em diferentes situações
  • ✓ Combinar loops e condicionais para lógica complexa
  • ✓ Evitar loops infinitos acidentais

Recursos inclusos:

  • 📹 10 vídeo-aulas com diagramas de fluxo
  • 📊 Diagramas visuais de lógica
  • 💻 Projetos práticos com loops e condicionais
  • 🔄 Exemplos de diferentes tipos de loops

Detecção de Colisão

A detecção de colisão permite verificar quando dois sprites se tocam. Esse é um conceito crítico para criar games interativos onde objetos podem colidir, pegar itens ou ativar eventos especiais.

O que você vai aprender:

  • Tocando em outro sprite? - Detecte quando um sprite toca em outro sprite específico.
  • Tocando em uma cor? - Implemente colisão com cores específicas no palco.
  • Tocando na borda? - Detecte quando um sprite atinge a borda do palco.
  • Distância entre sprites - Use cálculos de distância para colisões mais precisas.
  • Efeitos de colisão - Crie sons, efeitos visuais e mecânicas ao colidir.

Objetivos:

  • ✓ Implementar sistemas de colisão funcionais
  • ✓ Criar interações entre sprites
  • ✓ Desenvolver mecânicas de game baseadas em colisão
  • ✓ Otimizar detecção de colisão para performance

Recursos inclusos:

  • 📹 7 vídeo-aulas práticas
  • 🎮 Projetos de exemplo com colisão
  • 📐 Guia de matemática de colisão
  • 🎯 Desafios de implementação de colisão

Sistema de Pontuação

Um sistema de pontuação rastreia o progresso do jogador e fornece feedback sobre seu desempenho. Aprenda a criar contadores dinâmicos, pontos bônus, multiplicadores e exibições de score.

O que você vai aprender:

  • Variável de pontos - Crie uma variável para armazenar a pontuação do jogador.
  • Incrementar pontos - Aumente a pontuação quando eventos específicos ocorrem.
  • Exibir pontos - Mostre a pontuação na tela de forma clara e atraente.
  • Recordes e histórico - Implemente sistema de pontuação máxima e histórico de pontos.
  • Pontos bônus e multiplicadores - Crie mecânicas avançadas de pontuação para maior engajamento.

Objetivos:

  • ✓ Criar sistemas de pontuação funcionais
  • ✓ Implementar feedback visual de pontos
  • ✓ Armazenar e exibir recordes
  • ✓ Usar pontuação para mecânicas de game

Recursos inclusos:

  • 📹 6 vídeo-aulas sobre pontuação
  • 🎮 Projetos com sistema de pontos completo
  • 📊 Templates de exibição de pontuação
  • 🏆 Exemplos de leaderboards e recordes

Múltiplos Níveis

Criar múltiplos níveis adiciona profundidade e rejogabilidade aos seus games. Aprenda a estruturar níveis com dificuldade progressiva, transições entre níveis e gerenciamento de estado.

O que você vai aprender:

  • Estrutura de níveis - Organize seu jogo em múltiplas cenas (níveis) com estrutura clara.
  • Variável de nível - Use variáveis para rastrear em qual nível o jogador está.
  • Transições entre níveis - Implemente transições suaves e feedback de progresso.
  • Dificuldade progressiva - Ajuste velocidade, obstáculos e desafios conforme o nível aumenta.
  • Menu de seleção de nível - Crie interfaces para o jogador selecionar ou desbloquear níveis.

Objetivos:

  • ✓ Estruturar games com múltiplos níveis
  • ✓ Implementar progressão entre níveis
  • ✓ Criar dificuldade dinâmica
  • ✓ Desenvolver menus de seleção de nível

Recursos inclusos:

  • 📹 8 vídeo-aulas sobre estrutura de níveis
  • 🎮 Projeto completo com 5 níveis funcionais
  • 📋 Template de progressão de dificuldade
  • 🎯 Desafios de design de níveis
